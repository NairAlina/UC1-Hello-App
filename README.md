# HelloApp - UC1

This repository contains a simple Java program that prints "Hello, World!" to the console.

## Program
HelloApp.java

## Description
This program demonstrates the basic structure of a Java program including:
- Class declaration
- Main method
- Printing output using System.out.println()

## How to Compile

javac HelloApp.java

## How to Run

java HelloApp

## Output
Hello, World!
